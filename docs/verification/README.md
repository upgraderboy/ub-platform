# Verification Proofs Directory

This directory stores visual evidence (screenshots and video screen recordings) demonstrating that features were fully tested and working as expected at the time of implementation.

## Structure
* `screenshots/`: High-resolution `.png` screenshots of verified UI states, responsive views, and completed flows.
* `recordings/`: `.webp` or `.mp4` video recordings of interactive animations, terminal interactions, and browser navigation flows.

All media stored here must be linked directly in `docs/01_PROJECT_TRACKER.md`.

## 🚨 The Zero-Clutter Law
* **Do NOT save broken tests or intermediate debugging sessions here.**
* Media must **only** be saved at the very end when the feature is 100% working, responsive, and completely bug-free.
* Maintain clean naming: `<feature-name>-<desktop|mobile>.<png|webp>`.
